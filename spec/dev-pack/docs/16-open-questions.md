### Settings each organization chooses at setup (no CanDo default)

The owner left these to each organization in the Module 02 to 05 and 08 reviews (`docs/23` §2.4, `docs/24` §2.3, `docs/25` §2.2, `docs/26` §2.2, `docs/29` §2.2). They are decided, not open: the setup wizard asks each one, and the feature that needs it stops with `SETTING_NOT_SET` until it is answered.

| Setting | What the organization chooses | Decision |
| --- | --- | --- |
| `recruit.screening_owner` | HR, the department or both screen and see applicants first | R1.5 |
| `recruit.missing_requirement` | A candidate missing a required qualification is flagged or screened out (starting choice; each posting can change it) | R2.5 |
| `recruit.candidate_retention` | Per province or the longest of all its locations, and its own minimum; never less than the law | R4.2 |
| `recruit.interview_scoring` | Every interview scored, or optional | R4.3 |
| `payroll.default_proration_method` | How each pay group prorates salaried pay for a partial period: calendar days, working days or scheduled hours, within the law | Module 03 R3.2 |
| `comp.acting_pay_method` | How non-union acting pay is set: a percentage above current pay, the acting job's minimum, the higher of the two, or the first step above current pay | Module 04 R3.4 |
| `comp.acting_pay_percent` | The percentage for acting pay, where the method uses one | Module 04 R3.4 |
| `benefits.life_event_window_days` | Days after a life event in which an employee can change elections, where a plan sets none of its own | Module 05 R2.2 |
| `benefits.retro_adjust_months` | How many months back premium adjustments are made automatically; older ones go to HR | Module 05 R5.1 |
| `learning.request_hr_above_amount` | Cost of a training request above which HR approves as well as the manager (the starter route) | Module 08 R5.2 |
| `learning.repayment_without_rule` | What happens to a paid training request that none of the organization's repayment rules covers: HR decides, or no repayment | Module 08 R5.3 |

Module 08 also leaves to each organization its tuition repayment rules, by kind of training and cost, with no CanDo starting rule (`docs/29` §8.3).

Module 05 also leaves to each organization, as required fields and rules rather than settings: each plan's waiting period (and late-enrolment rule for kinds the starter does not cover), what happens to coverage during each unpaid non-statutory leave, and when coverage ends on termination for each class (`docs/26` §2.2).
